# 실기기 확인 항목

자동 검사는 화면 흐름, 시간 집계, API 오류 처리를 확인합니다. 다음 항목은 실제 Android 기기와 실제 백엔드에서 별도로 확인해야 합니다.

1. Android 8 이상 기기에 debug APK를 설치합니다. 카메라 거부·재요청·설정에서 허용·권한 회수 후 복귀를 확인합니다.
2. 스마트폰을 책상 높이, 측면 90도, 거리 1~1.5m에 세워 놓습니다. 귀·어깨·골반이 가려진 동안 자동 시작하지 않아야 합니다.
3. 구도 3초 안정 후 3→2→1 카운트다운, 중간 흔들림 시 초기화, 전면/후면 전환, 영상/스켈레톤 정렬을 확인합니다.
4. 구도 카운트다운 후 개인 기준 측정 없이 세션이 시작되는지 확인합니다. 정상·머리 내밀기·상체 앞으로 숙이기·고개만 숙이기·자리비움을 시험합니다. 세 가지 앞으로 숙인 자세는 거북목으로 집계합니다. 파일럿에서는 책이나 노트를 내려다볼 때의 오탐도 확인합니다.
5. 알림 소리·진동·끄기, 30초 쿨다운, 한국어 TTS가 없는 기기의 무음 폴백을 확인합니다.
6. 일시정지, 앱 전환, 화면 잠금, 화면 회전을 확인합니다. 백그라운드에서는 자동 일시정지하고 수동으로 재개해야 합니다. 촬영 중에는 화면 꺼짐 방지가 적용됩니다.
7. 진행 중 앱 프로세스를 종료합니다. 다시 열었을 때 마지막 체크포인트까지 '중단 복구'로 표시되어야 하며 이후 시간을 덧붙이지 않아야 합니다. 저장 간격은 최대 5초입니다.
8. 자정 전후 세션이 시작일(Asia/Seoul)에 집계되는지 확인합니다. 데모 세션은 달력과 서버 전송에서 제외되어야 합니다.
9. HTTPS 서버를 연결합니다. 비행기 모드에서 종료→앱 강제 종료→연결 복구 뒤 1건만 업로드되는지 확인합니다. 401·400·5xx는 모의 서버 테스트와 같은 분기로 동작해야 합니다.
10. 사용자 전체 삭제의 성공/실패, 로컬 개별 삭제, 로컬 전체 삭제를 구분해서 확인합니다.
11. 처리 지연·발열·1시간 배터리 소모는 기기 모델과 OS를 기록해 실측합니다. 5fps와 저전력 1fps는 분석 호출 간격이며 실제 처리량 보장값이 아닙니다.

이번 작업에서는 실기기 카메라 정확도, 발열·배터리, 실제 서버 연동을 측정하지 않았습니다. 자동 화면 테스트는 카메라 권한 없이 데모 모드를 사용합니다.
